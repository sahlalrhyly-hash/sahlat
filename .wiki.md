# Project Summary
The project "عقار" (Aqar) is an innovative real estate platform designed to streamline property transactions and management. It provides tools for property discovery, account management, and advanced search capabilities, enhancing interactions between buyers and sellers. The platform includes a web application and a Progressive Web App (PWA) for mobile access, ensuring continuous service availability. Recent updates have integrated Firebase for user authentication and data management, significantly improving user experience. The application is currently in demo mode, allowing users to explore functionalities without needing Firebase keys, and is prepared for deployment on Android and iOS. A new version has been successfully published, and the application is currently operational.

# Project Module Description
- **Main Page**: Displays properties with a search bar for filtering by city and property type.
- **Property Details Page**: Provides detailed information about selected properties, including images and contact options for owners.
- **Add Property**: User-authenticated form for adding new properties, supporting multiple images and videos, and includes fields for property details such as title, type, price, and location.
- **Edit Property**: Enables users to modify existing property details and media.
- **Map View**: Interactive map representation of properties based on geographic locations.
- **Profile Management**: Users can manage their profiles and listed properties.
- **Authentication**: Manages user login, registration, and session management using Firebase.
- **Notifications**: Alerts users about new messages, property updates, and favorites.
- **Messaging**: Facilitates direct communication between users regarding properties.
- **Settings**: Users can manage language preferences and other settings.
- **Admin Panel**: For managing users and properties.

# Technology Stack
- **React**: Frontend framework for building user interfaces.
- **TypeScript**: Provides type safety and enhances JavaScript.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **Vite**: Fast build tool for modern web applications.
- **Zustand**: State management library for React.
- **Firebase**: Backend service for user authentication, Firestore database, and storage.
- **Capacitor**: Tool for building native mobile applications.

# Usage
1. Install dependencies: Run `pnpm install` in the frontend directory.
2. Build the application: Use `pnpm run build` to compile the code.
3. Run the application: Use `pnpm run dev` to start the development server.
4. For Android deployment, follow the steps in `DEPLOYMENT_GUIDE.md`.
